# AR-JEN Clinic System Context

This file serves as a persistent brain for the AR-JEN Clinic Modernization project to ensure context is retained across sessions.

## 🚀 Project Overview

The AR-JEN Clinic portal is being modernized into a full-stack web application. The goal is to provide a patient-facing dashboard, smart scheduling system, and a robust backend for managing clinic operations.

## 🛠️ Technology Stack

- **Framework**: Next.js (Version 16.2.3)
- **UI Library**: React (Version 19.2.4)
- **Styling**: Tailwind CSS v4, shadcn/ui components (Radix UI)
- **Database/Backend**: Supabase (using `@supabase/supabase-js`, `@supabase/ssr`)
- **Icons**: Lucide React

## 🎯 Current Phases & Goals

1. **Smart Scheduling & Automated Blocking (Phase 1)**
   - Granular, admin-configurable scheduling.
   - Dynamic auto-saving capacity management.
   - Independent Saturday and Sunday booking blocks.

2. **Patient Dashboard & Consultation Messaging (Phase 3)**
   - Patient-specific navigation.
   - Database schema for consultation threads.
   - Messaging interface for direct communication between patients and clinical staff.
   - Currently working on: `app/patient/history/page.jsx`
